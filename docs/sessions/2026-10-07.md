# 2026-10-07 - From nothing to a working app

## Asked

A Mac desktop notation app in the spirit of Dorico, MuseScore, Sibelius and
Notion, whose music mostly comes from the family's generators: a grid of
staves that lines notes up, mouse, keyboard and MIDI input, automatic
engraving, playback through virtual instruments, chord and scale detection on
the timeline, click-to-preview, MIDI and audio export, automatic CCs, and
instrument awareness. Later: automation, articulations, VST3 and CLAP. Partway
through: no Intel build.

## Built

The whole first version - see the README. The core (score, engraver,
detection, AutoCC, MIDI and project files, edits) is plain C++ with 48 tests;
the five generators run unchanged through embedded Lua; the app is JUCE 8.

## The route

- **The engines turned out to be pure.** Every `*_theory`, `*_idea`,
  `*_catalogue`, `*_vary` file has no `reaper.` in it - the house rule paid off
  here. That decided 0003: run them, do not port them. All five adapters
  worked through a plain `lua5.4` harness before any C++ touched them
  (`tools/try_generators.lua`), which is where to test an adapter change.
- **The first render was nearly right**, which is what porting Starting Blocks
  Notation's rules buys. What the renders then showed: a final drum hit written
  as a sixteenth and a sixteenth rest (now a beat, to the bar line); and two
  heads on the same line (C and C#) drawn on top of each other - the
  crossed-head rule only looked for seconds, not unisons.
- **Three failing tests were the tests' fault.** C3 is the bass clef's second
  space, not line; C and C# is a unison on one line, not a second; and clicking
  the line under the staff in D major is C#, not C. Each was checked against
  the music before the expectation was changed.
- **The engraver was quadratic** in three places (rests, spacing, auto-voices
  each walked every element for every measure). Bucketing by measure took 200
  bars of eight busy parts to a quarter of a second in a debug build; a test
  holds it there.
- **Inserting a multi-part result crashed in principle**: it kept a pointer to
  the target part while pushing new parts onto the same vector. Caught reading
  it back, before it ever ran.
- **The chord lane named a tune**: "C D", "A B" for eighth notes of a melody.
  A segment is now named only where notes overlap, or where three or more
  pitch classes all belong to the chord found (an arpeggio, not a scale run).
- **Four notes of C major read as A minor** in the Scale lane. Midi Suggester's
  key finder cannot tell relatives apart on so little, and its fix (the last
  note) did not decide it. The written key signature now settles a near tie
  (+0.12); a clearly minor progression still reads minor under a C major
  signature, and a test says so.
- **Typed notes started in the wrong register** - a viola part's first C was a
  violin's. A part with no notes before the caret now starts in the middle of
  the instrument's sweet register.
- **Cmd+Z did nothing** on Linux: with a modifier held the key code arrives
  lower-case. Letters are compared upper-cased now.
- **JUCE 8 removed the blocking `runThread`** on progress windows; audio export
  owns its window and finishes in `threadComplete`.
- The session's worker restarted once mid-way. Nothing was lost, but nothing
  had been pushed either: commit early.
- **The Mac build compiled first time; a test failed only there.** It read a
  key's label through a reference into a temporary vector - undefined, and
  happened to work with GCC. Tests now keep what they read.
- **Proving the Mac's sound without a Mac**: `NoteratorAppTests` renders a bar
  through each synth and checks the WAV is not silent. On the macOS runner it
  prints "rendering through Apple General MIDI (built into macOS)" with an RMS
  of 0.023 - the Audio Unit loads and plays.
- **Suggester's chords overwrote the tune they were made for**, because every
  result went into the caret's part. Decision 0011.

## Not done yet

- The window has never been opened on a Mac by a person. Everything under it
  (build, tests, Apple's synth, packaging) runs on the macOS CI runner.
- No page view, dynamics, articulations, slurs, CC drawing, plugin hosting,
  MusicXML, or Windows build.
- Real-time MIDI recording (step input only for now).
- Two voices per staff at most; a third overlapping line is cut short in the
  notation (it still plays).
