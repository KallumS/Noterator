# 2026-10-09 - Follow the playhead, switchable

Done alongside Miderator (KallumS/Miderator), which was copied from this
repository that day and shows the same music on a piano roll.

## Asked

An auto-scroll option in both apps: the screen scrolls right when the music
playing is about to go out of view.

## Done (0033)

- The page already followed the playhead, but only once it was 40 pixels
  from the edge, and always. The rule is now `followScroll` in
  `Source/Core/Follow.h`: turn the page a margin before the edge (8% of the
  view, 24 to 120 pixels), the playhead landing that margin in from the
  left; go to a playhead that is off the screen.
- **Follow** beside Play, and in the Play menu, switches it; on by default
  and remembered between launches.
- Three core tests (69 now). The same file goes to Miderator.

## Checked

- The rule is tested as arithmetic: there is no sound card in the container,
  so the playhead never moves here and the page turning has not been seen;
  the Mac build is where it can be.
- In the window under Xvfb: the button fits the toolbar, shows on (yellow)
  at first, a click turns it off with a line in the status bar, and it is
  still off after the app is closed and opened again.

## Not done yet

- Smooth scrolling (the playhead fixed, the music moving under it) is a
  possible second mode; paging is the default every notation program uses.
